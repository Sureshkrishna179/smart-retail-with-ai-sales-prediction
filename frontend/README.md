# Frontend (SPA)

Static dashboard served by the Python API at `/`.

| File | Role |
|------|------|
| `dashboard.html` | Main shell and sections |
| `app.js` | API client, charts, navigation |
| `styles.css` | Theme and layout |

**Do not open `dashboard.html` as a file.** Always use `http://localhost:<PORT>/` from the running server.
